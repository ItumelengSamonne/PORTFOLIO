02 About

Two disciplines, one question: clarity

I started in spreadsheets and ended up in both a Jupyter kernel and a code editor. The through-line is the same question — how do you make something complicated look obvious?

I'm a first-year Data Science student at Sol Plaatje University in Kimberley. On the data side I'm building foundations: statistics, probability, calculus, algebra, data structures, algorithms and numerical methods. On the office side I'm genuinely strong in Excel, Access, Word and PowerPoint — the tools most businesses actually run on. On the web side I write HTML, CSS and JavaScript by hand.

I care about the handoff. A model nobody trusts is a spreadsheet with extra steps, and a dashboard nobody can read is a screenshot. So I want to build the whole path: the data, the analysis, the interface, and the note that explains what it does not do.

  • Explain the model, not just the score. Honest numbers, clear limits, no hype.
  • Ship the interface too. If the output needs a translator, it isn't finished.
  • Accessible by default. Keyboard paths, AA contrast and reduced-motion support from the first commit.
  • Strong in the basics. Excel, Access, Word and PowerPoint are first-class skills, not afterthoughts.
